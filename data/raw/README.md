# Raw Dataset

## Project
PhishShift Message Risk Scanner

## Purpose
This folder stores the original dataset used for phishing and social engineering message analysis.

## Data Preparation
The original dataset is preserved in this folder.

A separate processed dataset is created after cleaning and validation. Duplicate records and missing values are checked, and records with conflicting labels are excluded from the training dataset.

## Dataset Description
The dataset contains English messages belonging to six categories:

- Phishing
- Malware
- Scareware
- Baiting
- Pretexting
- NOT-Malicious General Class
